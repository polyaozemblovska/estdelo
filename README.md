# Есть дело — HR-прототип

Десктопный интерактивный прототип управления вакансиями: список → пять шагов → предпросмотр → имитация публикации. React, Vite, Inter (400/500/600/700), SVG из предоставленного архива Figma.

## Посмотреть без установки

Откройте на GitHub файл [`prototype/estdelo.html`](prototype/estdelo.html), нажмите **Download raw file** (значок скачивания справа над файлом) и сохраните его на компьютер. Затем откройте сохранённый `estdelo.html` в Chrome двойным щелчком. На GitHub HTML отображается как исходный код; скачанный файл откроется как сайт. Node.js для этого варианта не нужен.

## Запуск

Требуется Node.js 20.19+ или 22.12+ (проверено на Node.js 24).

```sh
npm ci
npm run dev -- --port 5173
```

## Проверки и сборка

```sh
npm run build
npm run export
npm test
```

`dist/` — сборка для статического хостинга. `artifacts/estdelo.html` — автономный файл: скачайте и откройте в браузере. Шрифт, логотип и иконки встроены; сервер и внешние запросы не нужны. Локальное хранилище при открытии HTML-файлов зависит от браузера; для юзабилити-тестирования предпочтительнее статический хостинг.

Playwright использует установленный `/usr/bin/chromium`. На другой машине установите браузер (`npx playwright install chromium`); конфигурация автоматически использует его, если системный Chromium отсутствует. Тест автономного HTML требует предварительного выполнения `npm run build && npm run export`.

## Что работает

- Все пять шагов, возврат, сброс с подтверждением и редактирование из предпросмотра.
- Ошибки после потери фокуса, исчезающие после исправления. Группы проверяются при выходе из группы. Продолжение доступно только при корректно заполненном шаге.
- При удалённом формате скрыты офисная доступность и адрес; они не участвуют в проверке и предпросмотре. Город, условия и блок предоставляемых компанией возможностей остаются.
- Задачи, навыки, образование: добавление и удаление. Максимум 200 символов в одной задаче, как ограничение в представленном примере.
- Вопросы кандидату: до пяти, удаление, перестановка мышью и кнопками со стрелками, обязательность созданных полей при включённой настройке. Настройки отклика и доступности не требуют принудительного включения.
- Черновики и опубликованные вакансии сохраняются в localStorage этого браузера. Вкладки списка, поиск, сортировка, фильтр формата, пагинация, приостановка и архивирование.

## Материалы и ограничения

Интерфейс восстановлен по предоставленному растровому экспорту секции «Управление вакансиями» и исходным SVG. Прямого доступа к Figma нет; привязки между экранами и точные свойства слоёв недоступны. Inter подключён локально по просьбе автора. Логотип извлечён из растрового экспорта; остальные иконки взяты из переданного архива.

Недостающие значения справочников заполнены простыми демонстрационными вариантами. Город и образование допускают свободный ввод, чтобы не ограничивать тестирование неизвестными справочниками. Для недокументированной ошибки диапазона зарплаты использован поясняющий текст. Карта адреса и реальные отклики не подключены. Другие разделы бокового меню показывают уведомление о границах сценария. Аккаунтов, сервера и интеграций нет; данные не передаются наружу. Отдельный мобильный дизайн не создавался.

Публичная публикация сайта не выполнялась. Для публичной ссылки разместите содержимое `dist/` на статическом хостинге.
